<h1 align="center">Atlas</h1>

Atlas 是 Heliantheon 的管理台。一个 Turborepo 把共享门户和 Hermes、Chaos、Zwei 各自的管理界面收在一起，提供一个跨系统搜索、入口聚合、风格统一的运营体验。领域相关的共享能力放在 `packages/shared`；领域无关的基础组件统一来自 `@heliannuuthus/ui`。

Atlas is the Heliantheon admin workspace: a Turborepo that bundles the shared portal with focused administration apps for Hermes, Chaos, and Zwei. Shared domain utilities live in `packages/shared`; domain-independent primitives come from `@heliannuuthus/ui`.
